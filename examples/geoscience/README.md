# Geoscience demo samples

These fixed historical samples come from the committed `openbexi_quake` files:

- `json/earthquake_2024_08_23_19.json`: 9 earthquake events.
- `json/volcano_2024_09_13_00.json`: 3 volcano notices.

Upstream revision: `e5b1acc73e0cabaed4e8e77d53682570f5919110`.

The event details and IDs are retained. Timeline timestamps are expressed in
ISO 8601 UTC, and the earthquake namespace is normalized to `earthquake` so
namespace selection matches its configuration. These files are separate from
live data generated by `openbexi_quake` under `/data`.

`HBDS/workspace.json` reads these files directly, without running a collector.
Its demo model opens August 21 through September 20, 2024, showing both datasets.
The ingestion source is disabled to keep the committed samples read-only.
`HBDS/GEO_Workspace.json` reads the live `/data/earthquake` and `/data/volcano`
trees using a separate model centered on the current time.

Only these reviewed samples are listed in `release/public-files.json`.
Generated `/data` trees, indexes and saved filter profiles are not release assets.
