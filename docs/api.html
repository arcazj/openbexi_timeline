Time and pagination

Use from and to for inclusive overlapping time ranges, search for text, namespace for exact source selection, and kind for event/session/zone. Results sort by start then ID. limit defaults to 100 and is at most 1000; follow nextOffset.

GET /api/v1/datasets/dinausaurs/events?from=165&to=115
GET /api/v1/datasets/monet/events?from=1840&to=1900&limit=50

Numeric time stays in the model's declared unit, such as Ma. Calendar values include ISO dates and BCE years. Event records use data.title, start, optional end, and stable id.

Errors and compatibility

Errors use application/problem+json. A missing revision returns 428; a stale revision returns 412. Read-only resources reject changes with 405. Existing legacy sessions and SSE endpoints retain their routes. The legacy Swagger file is retained as a historical contract.
