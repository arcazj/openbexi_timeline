# Model and YAML editor

The public Monet example shows the five editor areas and live timeline preview
at [desktop](desktop.png), [narrow](narrow.png) and [phone](phone.png) widths.
These captures use public data and local editing with no credentials.

![Model editor at desktop width](desktop.png)

The browser test `Editor remains usable at desktop, narrow and phone widths`
in `tests/browser/model-editor.spec.mjs` checks horizontal overflow and captures
these layouts. Review generated captures before copying them into this directory.
See the [editor guide](../../model-editor.md) for editing and connected access.
